# LOOKWALK Production Deployment & Domain Setup Guide

This guide walks you through launching the **LOOKWALK** storefront on a custom domain using a modern, scalable architecture:

- **Front‑end:** React + Vite hosted on **Vercel**.
- **Back‑end:** Express + Node.js hosted on **Render** (or Railway).
- **Database:** Single **PostgreSQL** instance (Supabase/Neon).
- **Security:** JWT authentication, bcrypt‑hashed admin password, Helmet, rate‑limiting.

---

## 1️⃣ Purchase a Custom Domain

Choose an ICANN‑accredited registrar (e.g., Namecheap, Cloudflare Registrar, Hostinger). Follow the registrar’s UI to buy your desired domain (e.g., `lookwalk.com`).

### Quick‑Start with Namecheap
1. Go to https://www.namecheap.com and search for your domain.
2. Add to cart, enable **WhoisGuard / Domain Privacy** (FREE).
3. Complete checkout with your preferred payment method.
4. Keep the Namecheap dashboard open – you’ll need the DNS settings later.

---

## 2️⃣ Set Up a Free PostgreSQL Database

We recommend **Supabase** or **Neon** for a managed PostgreSQL instance.

1. Sign up at https://supabase.com (or https://neon.tech).
2. Create a new project → *Database*.
3. Copy the connection string (starts with `postgresql://...`).
4. Keep it handy – you’ll paste it into Render’s environment variables.

---

## 3️⃣ Deploy the Back‑end API (Render)

1. Sign in to https://render.com with your GitHub account.
2. Click **New** → **Web Service**.
3. Connect the **LOOKWALK** repository.
4. **Settings**:
   - **Name:** `lookwalk-api`
   - **Language:** `Node`
   - **Root Directory:** `server`
   - **Build Command:** `npm install`
   - **Start Command:** `node index.js`
   - **Instance Type:** **Free** (or Starter for no sleep).
5. Click **Advanced** → add the following **Environment Variables**:
   - `PORT=5000`
   - `NODE_ENV=production`
   - `DATABASE_URL=<your‑Postgres‑connection‑string>`
   - `JWT_SECRET=<strong‑random‑string>`
6. Click **Create Web Service**. Render will build and deploy the API.
7. Note the generated service URL (e.g., `https://lookwalk-api.onrender.com`).

---

## 4️⃣ Deploy the Front‑end (Vercel)

1. Sign in to https://vercel.com with GitHub.
2. Click **Add New → Project** and import the repository.
3. **Framework Preset:** `Vite` (auto‑detected).
4. **Root Directory:** `./`
5. **Build Command:** `npm run build`
6. **Output Directory:** `dist`
7. **Environment Variables:**
   - `VITE_API_URL=https://<your‑render‑url>/api`  _(replace with your Render service URL)_
8. Click **Deploy**. Vercel will give you a preview URL like `https://lookwalk.vercel.app`.

---

## 5️⃣ Connect Your Custom Domain to Vercel

1. In Vercel Dashboard → **Settings → Domains**, click **Add** and type your domain (e.g., `lookwalk.com`).
2. Vercel will show two DNS records:
   - **A Record** for `@` → `76.76.21.21`
   - **CNAME Record** for `www` → `cname.vercel-dns.com`
3. In your registrar’s DNS panel (Namecheap → **Advanced DNS**), add these records.
4. Save changes. DNS propagation may take 5 min – 2 h.
5. Vercel will automatically issue a free SSL certificate.

## 6️⃣ Pre‑Deployment Checklist
- Refer to [deployment_checklist.md](deployment_checklist.md) for a checklist of tasks.
### 🛡️ Security
- Update the admin password in `src/pages/Admin.jsx` (replace the default `admin123` with a bcrypt‑hashed value). Use the migration script or the admin UI to set a new password.
- Verify that `JWT_SECRET` is a strong random string and **never** commit it to source control.

### 📈 SEO & Indexing
- Ensure `public/index.html` contains a meaningful `<title>` and `<meta name="description" …>`.
- Add a **robots.txt** file in `public/`:
```
User-agent: *
Allow: /
Disallow: /admin
Sitemap: https://<your‑domain>/sitemap.xml
```
- Generate a `public/sitemap.xml` listing the main routes (`/`, `/products`, `/about`, `/contact`, `/track‑order`).

### ⚡ Performance
- Optimize product images (WebP, compressed) before uploading via the admin panel.
- Verify that API pagination works (backend uses `LIMIT/OFFSET`).

## 7️⃣ Verify the Live Site
1. Visit your Vercel domain (e.g., `https://lookwalk.com`).
2. Test the main flows: browsing products, adding to cart, checkout, and order tracking.
3. Log in to the admin panel and confirm you can create, edit, and delete products.
4. Check the **Network** tab in DevTools to ensure all API calls hit `https://<render‑url>/api` and include the `Authorization: Bearer <token>` header.

## 8️⃣ Razorpay Integration (Future)

- Add Razorpay SDK script to `src/pages/Checkout.jsx`.
- Create a server endpoint `/api/payment/razorpay` to generate order IDs.
- Store `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in Render environment variables.
- Follow Razorpay docs: https://razorpay.com/docs/

- Test payment flow (sandbox) if Razorpay configured.
- Monitor API health endpoint (`/health`) on Render.
- Review logs for errors and performance metrics.
